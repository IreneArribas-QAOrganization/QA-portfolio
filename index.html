"Vida Verde" Website – QA Manual & Automation

I performed Quality Assurance for a pre-existing web application, working within a cross-functional team under Scrum agile methodology. Project management was conducted in weekly sprints using Jira where I actively participated in sprint planning, dailies, and sprint reviews at the end of each sprint.

I designed test cases for user stories following the BDD methodology, based on defined acceptance criteria. I authored scenarios in Gherkin to ensure tests were readable and understandable for the entire team, managing them with AssertThat to maintain full traceability between requirements, tests, and results within Jira. Execution was performed per user story, recording results across both web and mobile environments. During each sprint, I conducted functional testing, followed by exploratory testing at the end of the cycle to identify defects not covered by predefined cases. Detected bugs were reported in Jira and linked to their corresponding user stories to ensure end-to-end traceability between requirements, tests, and defects.

At the close of each sprint, I prepared the Release in Jira and documented delivery-related information in Confluence, including comprehensive test plans, execution results, and the overall product quality status. Following the release, I identified the application’s core business flows and automated regression testing using Playwright and Pytest with Python. I integrated these tests into a CI/CD pipeline using GitHub Actions, configured to automatically run the regression suite on weekly basis, aligned with each sprint’s closure.

QA Portfolio – Web Developer & API Testing Specialist

I developed a Web portfolio in English with HTML5, CSS3, JavaScript and Git, integrating a contact form. This portfolio was built by customizing a template within Visual Studio Code and managed via GitHub Desktop.

The contact form is connected to an API powered by Supabase. I designed the database scheme and executed SQL queries for data insertion and verification of the data submitted through the form. I conducted API Testing with Postman, designing test suites covering GET, POST, PATCH, and DELETE requests. Also implemented automated assertions to validate positive and negative response codes, authentication rules, header structure, and response integrity.

Additionally, I set up a CI/CD pipeline using GitHub Actions, configuring Newman to automatically run the Postman test suites on every repository push.
